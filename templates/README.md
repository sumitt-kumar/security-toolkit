# Security Toolkit

A beginner-level cyber security web app built with Python and Flask.

## Features
- *Password Strength Checker*: checks length, uppercase, lowercase, numbers and symbols
- *Phishing URL Checker*: flags long URLs, @ symbol, IP addresses, missing HTTPS and suspicious words

## How to run
1. Install Python 3
2. Install Flask: py -m pip install flask
3. Run: py app.py
4. Open http://127.0.0.1:5000 in your browser

## What I learned
- Basics of Flask routing and templates
- Common phishing URL patterns
- How password strength is evaluated
